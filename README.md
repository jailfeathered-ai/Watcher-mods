# The Watcher (Minecraft 1.20.1, Forge 47.3.0)

Build: install JDK 17 + Gradle 8.1.1, then run `gradle build` in this folder.
The jar appears in `build/libs/thewatcher-1.20.1-forge-1.0.0.jar` -> drop it in `.minecraft/mods`.

No PC? Push this folder to a GitHub repo; the Actions workflow builds the jar
(Actions tab -> latest run -> Artifacts -> thewatcher-jar).
